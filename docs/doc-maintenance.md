# 文档维护约定

## 文档职责

- `README.md`：对外项目说明和文档入口。
- `work-roadmap.md`：按日期记录实际开发结果。
- `feature-list.md`：功能状态唯一清单。
- `plan-list.md`：优先级、实施步骤、验收和阻塞项。
- `STATUS.md`：当前电脑与分支的简短交接状态。
- `interview-core-qa.md`：求职问答材料，不参与项目进度管理。

## 开发结束后

1. 更新 `work-roadmap.md` 的改动和验证结果。
2. 同步 `feature-list.md` 中受影响功能的状态。
3. 同步 `plan-list.md` 的当前阶段、下一步和阻塞项。
4. 更新 `STATUS.md`，保证跨电脑交接信息准确。
5. 仅在对外定位、启动方式或部署方式变化时修改 `README.md`。

所有说明保持简洁、使用简体中文；命令、路径和代码标识保留原文。
